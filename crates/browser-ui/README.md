# MegaMan UI

Intrinsic MUI file tables and virtualized result/receipt collections. Native filenames remain separate from display labels. Revision-scoped selection supports cursor-only movement, toggle, range and additive range gestures; text editors retain their own shortcuts.

Find and ZIP browsing use bounded pages and explicit completeness/error state. Copy/Paste and ZIP extraction keep app-owned workers/results alive across navigation. A shared mutation gate includes pending native Paste reads and terminal receipts. Cancel dispatch precedes completed-offer admission; Back hides, and explicit acknowledgement releases results.

Short archive panes compact secondary source/metadata details while preserving actions, paging and actual rows. UI checks use resolved scenes; native integration and platform behavior need separate fixtures.
