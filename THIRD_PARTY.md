# Third-party software

MegaMan uses third-party Rust crates under their respective licenses. Cargo.lock pins the dependency sources; Cargo metadata reports each package license and source location.

- MUI is MIT licensed: https://github.com/Matari-Audio/MUI/tree/f97d15be61a9f6643de8897b2c3385f39400fd3a
- The native drag/drop support dependency is MIT OR Apache-2.0: https://github.com/Matari-Audio/matari-audio-drag-and-drop/tree/c16eb00561894b6475963834f304e053638e7b94
- The Ubuntu font license is preserved in licenses/Ubuntu-font-LICENSE.txt.

Dependency source code is retrieved from the pinned public sources rather than copied into this repository. Dependencies keep their copyright notices and licenses.
