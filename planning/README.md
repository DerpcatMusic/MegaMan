# Project tracking

[Project board](https://github.com/users/DerpcatMusic/projects/4) · [Issues](https://github.com/DerpcatMusic/MegaMan/issues) · [Milestones](https://github.com/DerpcatMusic/MegaMan/milestones)

Issues own execution status and acceptance evidence; the public project shows Todo/In Progress/Done. Versioned docs define behavior and architecture. TRACKER.json maps work packages to GitHub objects and does not duplicate mutable status.

Close a work package only after its stated acceptance evidence holds. Local checks and exact native fixture manifests qualify their recorded scope; publication or compilation alone does not complete a platform/feature gate. No release dates or GitHub Actions wait are required.
